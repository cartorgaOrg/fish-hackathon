🐟 Fishathon Starter Kit

Build a game with characters that talk, listen and hold conversations, powered by Fish Audio. Start with the voice, then pick a sample game below to put it in.

🔊 Give your game a voice

The voice examples live next to this kit, in the fish-audio/ folder of the repo. Each one runs on its own with just a Fish Audio API key. Start with the simplest one that fits your idea:

cd fish-audio
cp .env.example .env          # paste your FISH_API_KEY (fish.audio/app/api-keys)
cd examples/01-tts-basics     # then follow its README
📣

Just speech

Narrator, NPC barks, cutscenes. Generate MP3s once, drop them in public/sounds/ and play them with game.audio.

Talk to an NPC

The player speaks, the NPC answers. Fish hosts the voice agent; your game sends it events and gets tool calls back.

Own pipeline

Full control: mic → speech-to-text → LLM → text-to-speech. For voice commands and custom turn-taking.

Not sure which one? Read fish-audio/docs/00-choose-your-path.md. Never put your FISH_API_KEY in game code: the browser talks to a small server, and the server talks to Fish Audio.

🎮 Pick a game to put it in

Eight playable sample games built from the same small set of reusable primitives, plus 780+ free CC0 models from KayKit and Quaternius. All of them have menus and work on phones. Copy the one closest to your idea with npm run new my-game -- --from <sample>.

🌱

Starter

The smallest complete game (~80 lines). Walk around and collect coins. Copy this one if you're starting from nothing.

games/starter/ 🎣
