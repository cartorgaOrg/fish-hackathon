Hackathon - Fish Audio Voice Playground

Two ways to give your game a voice. Pick one, press start, and talk to the NPC. Use headphones.

Fish runs the whole conversation. Your browser streams audio to a Fish voice agent over WebRTC. Fish handles speech recognition, the LLM, the voice and turn-taking, including interruptions.

Browser mic/speaker ⇄ WebRTC (LiveKit) ⇄ Fish agent: STT → LLM → TTS + turn-taking Local token server: creates the session, so your API key never reaches the browser
  • Game → NPC: the event buttons send silent text messages ("[GAME EVENT] ...") the agent reads but doesn't speak. The NPC's name and role go into its prompt when the call starts.
  • NPC → game: the agent calls client tools (open_gate, give_item) that run in the browser and change game state.
  • Best for: the fastest path to a natural, low-latency conversation. You control the prompt, events and tools, not each step.
  • Want your own LLM in the middle? Point the agent at your server: see examples/05-agent-custom-llm.

Code: examples/04-agent-web (mock game in src/game.ts; your real game can live anywhere). Needs FISH_API_KEY and FISH_AGENT_ID.

You run the conversation loop. Each step is a small, swappable module on your own server. Fish provides speech-to-text and the voice.

Browser: voice detection (runs locally) → audio clip → your server → Fish STT → your LLM → Fish TTS (sentence by sentence) → browser playback
  • Game → NPC: your server builds every prompt, so you inject any game state you like.
  • NPC → game: the LLM writes action tags like <action:open_gate>; your code parses them and updates state.
  • Best for: full control: custom turn-taking, any LLM (including a local one), several NPCs, push-to-talk as a game mechanic.
  • Trade-off: Fish STT works on finished clips, so each turn waits until you stop speaking.
  • No LLM_API_KEY set? The NPC answers with a fixed [MOCKUP] line. Set any OpenAI-compatible key in .env for real replies.

Code: examples/06-own-pipeline (mock game in game.py; your real game can live anywhere). Needs FISH_API_KEY.
